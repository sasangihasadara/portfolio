# Portfolio React Scaffold

This is a small Vite + React scaffold for your portfolio. It uses Tailwind CSS.

Quick start:

```bash
npm install
npm run dev
```

Notes:
- Tailwind is configured via `tailwind.config.cjs` and `postcss.config.cjs`.
- CDN scripts for Lucide icons and EmailJS are included in `index.html`.

If npm cannot install because of environment/network issues, you can open `portfolio-react.html` directly in a browser. It uses React + Tailwind from CDNs and does not require `npm install`.
